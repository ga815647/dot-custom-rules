# dot custom rules

這個公開 repo 用 Git 保存自訂規則的人工匯出快照，方便查看差異與歷史版本。

## 目前規則的來源

帳號「自訂規則」設定是唯一的生效來源。repo 中的檔案和 Git 歷史都是記錄，不會自動套用，也不能讓已修改或已刪除的規則重新生效。

## 檔案

- `README.md`：用途與更新方式
- `rules.json`：由目前帳號設定匯出的規則快照，包含匯出時間、來源版本及規則原文
- [`docs/slack-workflow.md`](docs/slack-workflow.md)：Slack 協作與 GitHub 通知的操作文件，不是新增規則或自動化設定

## 更新方式

1. 先在帳號設定中確認並完成規則變更
2. 從目前設定重新讀取規則，保留原文與版本資訊
3. 更新 `rules.json` 並提交 Git commit，簡短記錄這次變更
4. 比較 Git 歷史以查看差異；需要恢復舊規則時，仍須在帳號設定中重新確認變更

這個 repo 不包含自動同步、套用、排程或 CI 工作。
