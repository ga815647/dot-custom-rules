# 模型 effort 工作指引

更新日期：2026-10-08

這是使用者確認的工作偏好，不是帳戶自訂批准規則，不授予額外權限。後續使用者指示及現行帳戶規則優先。

## 目標

以每小時完成且驗證通過的工作量評估效率。計入規劃、等待、協調、測試及返工的總時間，不只比較單次推理速度或費用。

## 選擇方式

- 一般 Codex 開發任務預設 GPT-6.1 Sol high
- 範圍明確、容易驗證的小任務可用 medium
- 依階段難度、實際進度與返工情況調整 effort，不必固定沿用前一階段
- 只有更深入推理有望解決問題、減少總耗時時才提高 effort
- 網路、權限、額度及外部等待問題先處理原因，不靠提高 effort 解決
- 減少不必要的交接、重複審查與重跑，同時保留必要的測試與驗證

適用於可選擇模型與 effort 的工作入口。模型切換及任何操作仍遵守現行授權要求；本文件不取代帳戶規則。
